# Nails Bot — онлайн-запись на маникюр в Telegram

Telegram Mini App для записи к мастеру маникюра: клиент выбирает услуги, дату и время прямо внутри Telegram,
а мастер мгновенно получает уведомление и управляет услугами и графиком через админ-панель.

- **Бэкенд:** Python, FastAPI + aiogram 3 (один процесс), SQLite.
- **Фронтенд:** чистые HTML/CSS/JS + `telegram-web-app.js`, без сборки. Цвета берутся из темы Telegram
  (`--tg-theme-*`), используются нативные MainButton, BackButton, всплывающие окна и виброотклик.

## Возможности

**Клиент (Mini App)**

1. Главный экран: приветствие по имени, список своих будущих записей с возможностью отмены, кнопка «Записаться».
2. Выбор услуг — можно отметить несколько, длительность и сумма считаются автоматически.
3. Календарь со свободными днями и сетка свободных слотов (шаг 30 минут или 1 час — задаёт мастер).
   Слот предлагается, только если вся процедура помещается до конца рабочего дня и не пересекается с другими записями.
4. Контакты: имя подставляется из Telegram, телефон — кнопкой «Взять номер из Telegram» (`requestContact`)
   или вручную; при следующей записи номер подставится сам.
5. Итоговый экран с деталями и кнопкой «Подтвердить запись».

**Бот**

- `/start` — приветствие и кнопка «Открыть запись»; на старте бот ставит такую же кнопку меню (Menu Button).
- После записи клиент получает: «Ваша запись на [дата/время] успешно оформлена!».
- Мастеру (в личку или в отдельный чат) сразу приходит:
  ```
  Новая запись!
  Клиент: Анна (@anna) / +79991234567
  Услуга: Маникюр с покрытием, Дизайн
  Дата и время: 27 октября 2026 (вт), 10:00–12:00
  Сумма: 3 500 ₽
  ```
- Уведомления об отменах: мастеру, если отменил клиент, и клиенту, если отменил мастер.
- `/admin` — кнопка админ-панели (только для `ADMIN_IDS`), `/id` — показать ID пользователя и чата.

**Админ-панель мастера** (`/admin` в боте или ссылка на главном экране у мастера)

- **Записи:** предстоящие и прошедшие, сгруппированы по дням, с телефоном, @username и суммой; отмена записи.
- **Услуги:** добавление, редактирование, скрытие и удаление (название, описание, цена, длительность).
- **График:** шаг слотов (30 мин / 1 час), рабочие часы по дням недели, на сколько дней вперёд открыта запись,
  минимальное время до записи, выходные и отпускные дни.

Безопасность: каждый запрос к API подписан `initData` от Telegram, сервер проверяет подпись по токену бота.
Слот перепроверяется на сервере в момент записи, поэтому два клиента не могут занять одно время.

## Быстрый старт

### 1. Бот и HTTPS-адрес

1. Создайте бота у [@BotFather](https://t.me/BotFather) и скопируйте токен.
2. Mini App открывается только по **HTTPS**. Варианты:
   - сервер с доменом и обратным прокси (Caddy/nginx) на порт приложения;
   - для проверки на своём компьютере — туннель, например
     `cloudflared tunnel --url http://localhost:8080` или `ngrok http 8080`. Полученный `https://…` адрес укажите в `WEBAPP_URL`.

### 2. Установка

```bash
python -m venv .venv
```

```bash
.venv/bin/pip install -r requirements.txt
```

На Windows путь к pip: `.venv\Scripts\pip`.

### 3. Настройка

Скопируйте `.env.example` в `.env` и заполните как минимум `BOT_TOKEN`, `WEBAPP_URL` и `ADMIN_IDS`.
Свой Telegram ID можно узнать командой `/id` у бота (бот отвечает даже без `ADMIN_IDS`).
Чтобы уведомления приходили в группу, добавьте бота в группу, отправьте там `/id` и укажите ID группы в `MASTER_CHAT_ID`.

### 4. Запуск

```bash
python -m app
```

Сервер отдаёт Mini App и API на `PORT` (по умолчанию 8080), бот работает в том же процессе.
Откройте бота, нажмите `/start` → «Открыть запись». Мастеру: `/admin` → добавьте услуги и проверьте график.

## Режимы бота

| `BOT_MODE` | Как работает |
|---|---|
| `polling` (по умолчанию) | Бот сам опрашивает Telegram. Подходит почти всегда. |
| `webhook` | Telegram шлёт обновления на `WEBAPP_URL/tg/webhook`; задайте `WEBHOOK_SECRET`. |
| `off` | Бот не принимает команды, но уведомления отправляет. |

## Разработка

Посмотреть интерфейс в обычном браузере без Telegram (только локально!):

```bash
DEV_MODE=1 BOT_MODE=off python -m app
```

В режиме `DEV_MODE` API принимает запросы без подписи Telegram, а посетитель считается мастером:
откройте `http://localhost:8080/admin.html`, добавьте услуги, затем `http://localhost:8080/` для записи.
Нативные кнопки Telegram в браузере заменяются кнопками на странице.

Тесты:

```bash
pip install -r requirements-dev.txt
```

```bash
python -m pytest
```

Документация API: `http://localhost:8080/api/docs`.

## Структура

```
app/
  __main__.py       запуск: python -m app
  main.py           сборка FastAPI-приложения, запуск бота (polling/webhook), раздача webapp/
  config.py         настройки из переменных окружения / .env
  auth.py           проверка подписи initData
  api.py            API клиента (/api/...) и админ-панели (/api/admin/...)
  scheduling.py     рабочие часы и расчёт свободных слотов
  db.py             SQLite: услуги, записи, график, выходные, клиенты
  notifications.py  тексты и отправка уведомлений
  bot.py            команды бота и кнопка меню
webapp/
  index.html, js/app.js      клиентская часть
  admin.html, js/admin.js    админ-панель
  js/common.js, css/style.css
tests/              pytest: подпись, слоты, API, бот
```
