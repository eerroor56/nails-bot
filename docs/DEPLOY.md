# Установка бота на сервер мастера

У каждого мастера свой сервер в Нидерландах, оформленный на её имя, — в Timeweb Cloud или в Aeza, на выбор.
Она платит хостингу, вы один раз ставите бота и дальше обновляете его по SSH. Как оплачивать сервер,
мастеру объясняет памятка для её хостинга: «Как оплачивать бота для записи — памятка мастеру» (Timeweb Cloud)
или «Как оплачивать бота для записи (Aeza) — памятка мастеру».

**Почему Нидерланды, а не Россия.** С 2026 года с российских серверов адрес `api.telegram.org` часто недоступен:
соединение зависает, и бот не получает ни одного сообщения ([Хабр](https://habr.com/ru/sandbox/288226/),
[pressaff](https://pressaff.com/tg-news/ru-hostingi-nachali-rezat-vps-s-dostupom-k-telegram-api-nekotorye-rossijskie-hosting-provajdery/)).
Из Нидерландов Telegram доступен. Скрипт установки проверяет это сам и остановится, если связи нет.

**Чем за это платим.** Имена и телефоны клиентов хранятся за рубежом, а закон требует хранить персональные данные
россиян на серверах в России (ч. 5 ст. 18 закона 152-ФЗ). Если это станет важно, есть другая схема: сервер в России
и релей — небольшой прокси за рубежом, через который идут только запросы к Telegram.

| Кто | Что делает | Сколько платит |
|---|---|---|
| Мастер | Владеет аккаунтом у хостинга, пополняет баланс своей картой | 1 820 ₽/мес в Timeweb Cloud или 593 ₽/мес в Aeza |
| Вы | Ставите и обновляете бота, держите домен для адресов мастеров | Один домен на всех, раз в год |
| Клиенты мастера | Записываются через Telegram | Бесплатно |

Бот занимает около 150–200 МБ памяти, поэтому сервера с 1 ГБ хватает с запасом.

## Какой хостинг предложить

Скрипт установки одинаково работает на обоих: нужен сервер в Нидерландах (Амстердам) с Ubuntu 22.04 или 24.04.
Цены и правила — с сайтов хостингов на 26 октября 2026 года.

| | Timeweb Cloud | Aeza (кабинет aeza.ru) |
|---|---|---|
| Сервер | NL-15: 1 vCPU, 1 ГБ, 15 ГБ NVMe, канал 200 Мбит/с | NLs-1: 1 ядро, 2 ГБ, 30 ГБ NVMe, канал 1 Гбит/с |
| Цена | 1 820 ₽/мес | 593 ₽/мес, скидка 5–12% при оплате от 3 месяцев |
| Как списываются деньги | С баланса каждый час; карта сама пополняет баланс за 7 дней до конца денег | С баланса за месяц вперёд; автопродление в конце срока, только если на балансе хватает |
| Если мастер не заплатила | Аккаунт блокируется; 7 дней на оплату, можно взять отложенный платёж до 5 дней | Сервер останавливается; через 7 дней без оплаты всё удаляется, IP могут выкупить другие клиенты |
| Источник | [тарифы](https://timeweb.cloud/services/vds-vps?location=nl), [блокировка](https://timeweb.cloud/docs/cloud-servers/data-storage-after-block) | [тарифы](https://aeza.ru/virtual-servers), [оферта](https://aeza.ru/terms) п. 13.6.1, 13.7 |

## 1. Встреча с мастером (около 30 минут)

Делайте это вместе, на её телефоне или ноутбуке: SMS-коды и карта — её. Затем — общие шаги для обоих хостингов.

**Вариант А: Timeweb Cloud**

1. **Аккаунт** на её почту и телефон. Пополните баланс её картой — карта сразу привяжется
   для автоплатежа. Минимум 500 ₽; удобнее сразу на 3 месяца (5 460 ₽).
2. **Уведомления в Telegram:** «Настройки аккаунта» → «Уведомления» → блок «Телеграм» → «Подключить».
3. **Сервер:** раздел «Облачные серверы» → новый сервер: Ubuntu 24.04, Нидерланды, тариф NL-15
   (Premium: 1 vCPU, 1 ГБ, 15 ГБ NVMe). При создании добавьте **ваш** SSH-ключ.
   В блоке «Безопасность» советую включить «Отмена удаления»: случайно удалённый сервер
   можно будет вернуть в течение 72 часов.

**Вариант Б: Aeza**

1. **Аккаунт в российском кабинете [my.aeza.ru](https://my.aeza.ru/)** на её почту — не на aeza.net:
   там цены в евро и рубли пересчитываются по внутреннему курсу. Пополните баланс её картой или по СБП.
2. **Уведомления в Telegram:** настройки кабинета → страница «Безопасность» → привязка Telegram → «Старт» в боте Aeza.
   Там же включите двухфакторный вход.
3. **Сервер:** локация Амстердам, тариф NLs-1 (Shared: 1 ядро, 2 ГБ, 30 ГБ NVMe), Ubuntu 24.04.
   Срок — **месяц, не час**: почасовой сервер без оплаты удаляется через 24 часа.
   **Включите переключатель автопродления при заказе** — по умолчанию он выключен.
   Для входа используйте ваш SSH-ключ, если панель предлагает его добавить, или пароль root из карточки сервера.

**Общие шаги**

1. **Бот:** в её Telegram откройте [@BotFather](https://t.me/BotFather) → `/newbot` → сохраните токен.
   Имя, аватар и описание бота — на её вкус.
2. **Её Telegram ID:** например, через [@userinfobot](https://t.me/userinfobot).
3. **IP сервера** — в карточке сервера в панели.

Почему аккаунт на мастере, а не на вас: она платит напрямую и владеет данными своих клиентов.

## 2. Адрес для Mini App

Telegram открывает Mini App только по HTTPS, поэтому нужен домен.

- **По умолчанию — поддомен вашего домена.** В DNS вашего домена добавьте запись типа `A`:
  имя `anna`, значение — IP её сервера. Получится `anna.example.ru`. Мастеру платить за домен не нужно.
- **Если у мастера свой домен** — такую же `A`-запись она (или вы) добавляет у своего регистратора.

Проверить, что запись заработала (обычно от нескольких минут до часа):

```bash
nslookup anna.example.ru
```

## 3. Установка (около 5 минут)

Подключитесь к серверу:

```bash
ssh root@<IP сервера>
```

Поставьте git и скачайте код (если репозиторий приватный, понадобится токен доступа GitHub вместо пароля):

```bash
apt-get update && apt-get install -y git && git clone https://github.com/eerroor56/nails-bot.git /opt/nails-bot
```

Запустите установку — домен, токен бота, ID мастера и название студии:

```bash
bash /opt/nails-bot/deploy/install.sh anna.example.ru 123456789:AAH... 987654321 "Студия Анны"
```

Для другого часового пояса добавьте его перед командой: `TIMEZONE=Asia/Yekaterinburg bash /opt/nails-bot/deploy/install.sh ...`.

Скрипт сам:

- ставит Python и веб-сервер Caddy (он получает и продлевает HTTPS-сертификат);
- проверяет, что сервер может соединиться с Telegram, и останавливается, если нет;
- создаёт системного пользователя `nails` и ставит зависимости;
- записывает настройки в `/etc/nails-bot.env` (доступен только root — там токен бота);
- запускает службу `nails-bot` и настраивает Caddy на ваш домен;
- включает ночную резервную копию базы;
- в конце проверяет, что бот отвечает.

Если что-то пошло не так, скрипт можно запустить ещё раз: уже записанные настройки он не тронет.

## 4. Проверка и передача мастеру

1. Откройте `https://anna.example.ru` в обычном браузере. Страница «Что-то пошло не так — Откройте
   приложение через Telegram» означает, что всё работает: HTTPS есть, сервер отвечает.
2. Мастер нажимает **Start** в своём боте. Без этого бот не сможет присылать ей уведомления —
   в Telegram бот не пишет человеку первым.
3. Мастер пишет `/admin`, добавляет услуги и проверяет график.
4. Сделайте пробную запись со своего Telegram — мастеру должно прийти «Новая запись!». Потом отмените её.
5. Отправьте мастеру памятку об оплате для её хостинга (PDF), вписав в неё свои контакты.

Уведомления в группу вместо лички: мастер добавляет бота в группу и пишет там `/id`.
Впишите ID группы в `MASTER_CHAT_ID` (см. «Настройки» ниже).

## 5. Обслуживание

**Обновить бота у одного мастера** — с вашего компьютера:

```bash
ssh root@<IP сервера> 'bash /opt/nails-bot/deploy/update.sh'
```

**Обновить у всех.** Держите у себя файл `masters.txt` с IP серверов, по одному в строке:

```bash
while read -r ip; do echo "== $ip"; ssh -n "root@$ip" 'bash /opt/nails-bot/deploy/update.sh'; done < masters.txt
```

**Логи:**

```bash
ssh root@<IP сервера> 'journalctl -u nails-bot -n 100'
```

**Настройки** (название, часовой пояс, группа для уведомлений, новый токен) — в `/etc/nails-bot.env`.
После правки перезапустите бота:

```bash
ssh root@<IP сервера> 'systemctl restart nails-bot'
```

**Резервные копии.** Каждую ночь в 3:30 база копируется в `/var/backups/nails-bot/`, копии хранятся 30 дней.
Но они лежат на том же сервере: если мастер перестанет платить, через 7 дней после блокировки
хостинг удалит сервер вместе с копиями. Поэтому время от времени забирайте копии к себе:

```bash
scp "root@<IP сервера>:/var/backups/nails-bot/*.db" ./backups/anna/
```

Восстановить базу из копии (на сервере):

```bash
systemctl stop nails-bot && cp /var/backups/nails-bot/nails-2026-10-26.db /var/lib/nails-bot/nails.db && rm -f /var/lib/nails-bot/nails.db-wal /var/lib/nails-bot/nails.db-shm && chown nails: /var/lib/nails-bot/nails.db && systemctl start nails-bot
```

## 6. Если мастер перестала платить

- **Timeweb Cloud:** деньги закончились → аккаунт блокируется, бот не отвечает → через 7 дней сервер
  и все данные удаляются ([документация](https://timeweb.cloud/docs/cloud-servers/data-storage-after-block)).
- **Aeza:** срок сервера закончился без продления → сервер останавливается → через 7 дней без оплаты
  договор прекращается и данные удаляются ([оферта](https://aeza.ru/terms), п. 13.6.1 и 13.7).
  Неоплаченный сервер и его IP могут выкупить другие клиенты ещё раньше
  ([база знаний Aeza](https://wiki.aeza.ru/cabinet/auto-prolong/)).

В эти дни напомните мастеру об оплате. Если она решила уйти — заберите базу (`scp`, как выше)
и отдайте ей: это её клиенты.

## Если что-то не работает

Сначала логи: `journalctl -u nails-bot -n 50`. Проверить связь сервера с Telegram:

```bash
curl -m 10 -sS -o /dev/null -w '%{http_code}
' https://api.telegram.org
```

| Симптом | Причина и что делать |
|---|---|
| Сайт не открывается или ошибка сертификата | DNS-запись ещё не обновилась или не та. Проверьте `nslookup` и логи Caddy: `journalctl -u caddy -n 50` |
| Бот совсем не отвечает | Сервер не оплачен: в Timeweb Cloud проверьте баланс, в Aeza — что сервер продлён. Иначе — логи бота |
| В логах `TelegramNetworkError` или таймауты | Сервер не достучался до Telegram. Проверьте командой выше: ответ `302` — связь есть, таймаут — заблокировано, нужен сервер в другой стране |
| В логах `TelegramUnauthorizedError` | Неверный токен: мастер могла перевыпустить его в BotFather. Обновите `BOT_TOKEN` и перезапустите бота |
| В логах `Conflict: terminated by other getUpdates request` | Тот же токен запущен ещё где-то, например у вас на компьютере. Один бот — одна запущенная копия |
| Мастер не получает уведомления | Проверьте `ADMIN_IDS` и что мастер нажала Start в боте. Для группы — что бот в ней состоит |
| В админке «Нет доступа» | ID мастера не совпадает с `ADMIN_IDS`. Пусть она отправит боту `/id` — бот покажет правильный ID |
| `/admin` нет в меню команд | Мастер нажала Start после установки. Команда работает, если её набрать; в меню появится после `systemctl restart nails-bot` |
